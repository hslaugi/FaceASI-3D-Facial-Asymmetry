# FaceASI Hardware — Previous Prototype Design

This folder contains SolidWorks housing designs and CAD renderings from the **previous FaceASI Scope project**, described in the 2026 ASME Design of Medical Devices Conference paper [1]. The housing design is discussed in Section 2.3 (*Housing*) and illustrated in Figure 3 of that paper.

These files document the **earlier prototype design** on which the current Senior Design project builds. The renderings are CAD images, **not photographs of the assembled device**.
