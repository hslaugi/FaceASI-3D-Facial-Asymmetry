## Changes made for the public repository

- The Python v62 algorithms and application behavior were retained; its entry-file name and the introductory command example were updated to `Python_FaceAssymmetry.py`.
- The MATLAB scan-processing code and interface were retained. Its entry function, matching file, and internal GUI callback were renamed to `MATLAB_FaceAssymmetry`. The previous packaging pass excluded a human facial recording and its demo-only loader from the public version.
- Documentation, dependency lists, repository integrity checks, and automated non-hardware tests were added.
